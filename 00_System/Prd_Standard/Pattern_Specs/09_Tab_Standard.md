# 🗂️ Pattern Spec: 标签页标准 (Tab Standard)

## 1. Tab 定义矩阵
| 标签名称 | 激活键 (ActiveKey) | 包含组件 | 徽标提醒 (Badge) | 访问权限 |
| :--- | :--- | :--- | :--- | :--- |
| 基础信息 | `basic` | `Descriptions` | 无 | 全员 |
| 费用明细 | `billing` | `Table` | 显示欠费金额 | 财务/主管 |
| 附件管理 | `files` | `UploadList` | 显示附件个数 | 全员 |

## 2. 行为规范
- **持久化记录**：用户切换 Tab 后，刷新页面或点击返回再进入，必须通过 URL 参数（如 `?tab=billing`）锁定上次选中的标签。
- **按需加载 (Lazy Load)**：只有在用户点击该 Tab 时，才初始化其内部的组件并请求 API，严禁一次性加载所有 Tab 内容。
- **销毁规则**：除非有特定业务需求（如正在编辑），否则切换 Tab 时不应销毁上一个 Tab 的状态，保持切换流畅。

## 3. UI 红线
- **样式统一**：全局统一使用 AntD `line` 或 `card` 样式，禁止在同一项目内混用。
