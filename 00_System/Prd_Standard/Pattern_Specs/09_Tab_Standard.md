# 09 标签页写作标准

## 1. Purpose

本规则用于帮助在 PRD 中把标签页切换写清楚。

## 2. When To Use

适用于：

- 详情页标签区
- 分区管理页
- 多视角内容切换页

## 3. Core Writing Points

- 写清楚有哪些标签页
- 写清楚每个标签页承载什么内容
- 写清楚切换后状态是否保留
- 写清楚是否按需加载
- 写清楚权限差异和提醒信息

## 4. Typical Veto

- 有标签页，但每页内容和边界不清
- 切换逻辑完全没写

## 5. Typical Guide

- 可补标签矩阵
- 可补状态保留和权限规则
