# 📖 Pattern Spec: 详情描述标准 (Detail Standard)

## 1. 数据展示矩阵 (Attribute Matrix)
AI 必须为详情页的每一项数据定义以下属性：
| 字段名称 | 数据路径 (Key) | 格式化规则 | 交互行为 | 视觉逻辑 (Badge/Tag) |
| :--- | :--- | :--- | :--- | :--- |
| 示例：运单号 | `waybill_no` | 原始文本 | 点击复制 (Copy) | N/A |
| 示例：重量 | `weight` | 数值 + " KG" | N/A | N/A |
| 示例：当前状态 | `status` | 映射为中文 | N/A | 0:待发(Blue), 1:派送中(Orange) |

## 2. 交互与布局逻辑
- **布局栅格**：默认采用 AntD `Descriptions`。通常为 3 列（大屏）或 2 列（中屏）。
- **空值处理**：若字段数据缺失，统一显示横杠 `"-"`。禁止留白，禁止显示 `null`。
- **敏感信息隐藏**：涉及手机号、身份证、个人隐私字段，默认展示掩码（如：138****0001），点击图标后脱敏显示。

## 3. UI 视觉红线
- **Label 风格**：Label 文字颜色统一为灰色 (#8c8c8c)，Value 颜色为深色 (#262626)。
- **分组标题**：多模块详情必须使用 `Title` + `Divider` 进行物理隔离。
