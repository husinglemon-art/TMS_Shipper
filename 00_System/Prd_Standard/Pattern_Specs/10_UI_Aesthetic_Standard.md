# 💎 Pattern Spec: 欧美简约主义与视觉秩序标准 (Aesthetic Standard v2.0)

> **[核心审美]**：内容即界面。我们崇尚 Linear 的硬朗与 Stripe 的通透。
> **[严禁事项]**：严禁大模块堆砌、严禁深色粗边框、严禁五颜六色、严禁信息无序堆叠。

---

## 1. 间距哲学：呼吸感 (Airy Negative Space)
- **8px 律动**：所有 Padding/Margin 必须基于 8px。
- **内容边距**：主容器内边距建议 `32px - 48px`，拒绝紧凑。
- **模块分割**：禁止为了区分功能而画厚重的 Card。优先使用 **32px+ 的垂直间距** 或 `1px #F0F0F0` 的极细分割线。

## 2. 排版即设计 (Typography-First)
- **视觉锚点**：
  - 页面大标题：`24px - 30px`, Font-Weight 600, 颜色 #1A1A1A。
  - 辅助说明：`12px`, 颜色 #8C8C8C (仅在必要时出现)。
- **留白对比**：通过极大的标题与极精简的正文对比，创造“大气”的视觉张力。

## 3. 反堆砌逻辑 (Anti-Clutter Rules)
- **去背景化**：除了主操作区，尽量保持背景为纯白 (`#FFFFFF`) 或极淡灰 (`#FAFAFA`)。
- **渐进式暴露**：
  - 超过 5 个字段的表单必须分步或分组隐藏。
  - 默认隐藏不常用的操作（放进 `Dropdown` 或 `More`），保持界面只有“当前最重要”的元素。

## 4. 阴影与深度 (Subtle Elevation)
- **影子美学**：严禁使用默认大阴影。
- **参数标准**：`box-shadow: 0 1px 2px 0 rgba(0, 0, 0, 0.03), 0 1px 6px -1px rgba(0, 0, 0, 0.02)`。
- **效果**：卡片应像轻薄的纸张浮在桌面，而非厚重的砖块沉在页面。

## 5. 交互流程 (Flow Continuity)
- **平滑过渡**：所有 Modal 弹出、Sider 收缩、Tab 切换必须带 `0.2s ease-in-out` 过渡。
- **吸底动作栏**：对于长表单，底部动作栏（Save/Cancel）采用半透明毛玻璃效果，保持流程的贯通感。
