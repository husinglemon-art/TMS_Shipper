# 📋 Pattern Spec: 数据列表标准 (Table Standard)

> **[引用准则]**：所有数据展示列表必须遵循本标准。AI 在填充具体页面 PRD 时，必须强制说明数据来源与排序逻辑。

---

## 1. 展示数据规则 (Data Display Rules)
> **这是列表的“生命线”，必须明确定义数据获取的背景。**

### 1.1 数据源声明 (Data Source)
AI 必须明确以下三点：
- **核心实体**：数据属于哪个业务对象（如：`Waybill_Master` 运单主表）。
- **初始化行为**：
  - `Auto`: 进入页面立即加载。
  - `Manual`: 必须点击查询后才加载。
- **数据范围**：是否有预设过滤条件（如：默认只显示“近 30 天内”或“状态 != 已删除”的数据）。

### 1.2 排序规则 (Sorting Logic)
- **默认排序 (Initial Sort)**：页面打开时，默认按哪个字段排序？（如：`created_at` 降序）。
- **手动排序 (Manual Sort)**：哪些列支持用户点击表头切换排序？（必须在下表中标注）。
- **排序权重**：若存在多级排序，需说明优先级。

---

## 2. 表头与数据映射矩阵 (Column Mapping)
| 表头名称 | 数据字段 (Key) | 格式化/翻译逻辑 | 排序支持 | 宽度/对齐 |
| :--- | :--- | :--- | :--- | :--- |
| 运单 ID | `waybill_id` | 蓝色加粗, 点击跳转详情 | **DESC (默认)** | 150px / Left |
| 创建时间 | `created_at` | 格式: YYYY-MM-DD HH:mm | 支持排序 | 180px / Left |
| 当前状态 | `status` | 0:待发(Blue), 1:运行(Green) | 仅支持过滤 | 100px / Center |
| 预估金额 | `amount` | `currency` 格式化, 两位小数 | 支持排序 | 120px / Right |

---

## 3. 分页与加载逻辑 (Pagination & Loading)
- **分页规格**：默认每页条数（建议 20 条/页），是否支持用户切换每页条数。
- **加载反馈**：数据请求期间，Table 必须开启 AntD `loading={true}` 遮罩。
- **空态处理**：若无数据，展示 Empty 图标，文案统一为：“未查询到相关资产，请尝试调整筛选条件。”

---

## 4. 交互红线与样式 (UX Red Lines)
- **行操作**：点击行内“编辑”或“详情”时，采用 `Drawer` 还是 `Modal`？
- **多选逻辑**：是否支持 `Checkbox` 批量操作？若支持，需说明“全选”后的逻辑。
- **自适应**：列表必须支持 `scroll={{ x: 'max-content' }}`，防止在小屏幕下字段挤压变形。
