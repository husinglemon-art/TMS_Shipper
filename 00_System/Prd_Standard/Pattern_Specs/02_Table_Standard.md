# 02 列表区写作标准

## 1. Purpose

本规则用于帮助在 PRD 中把数据列表写清楚。

## 2. When To Use

适用于：

- 列表页
- 明细页中的子列表
- 需要分页或排序的数据区

## 3. Core Writing Points

- 写清楚数据对象是什么
- 写清楚默认加载方式
- 写清楚默认排序和手动排序规则
- 写清楚表头字段和格式化逻辑
- 写清楚分页、空状态和行操作方式

## 4. Typical Veto

- 列表里展示什么字段都不清楚
- 没有分页、排序或空状态说明

## 5. Typical Guide

- 可补字段表格
- 可补行操作说明
- 可补多选或批量操作逻辑
