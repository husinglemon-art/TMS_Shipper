# ⏱️ Pattern Spec: 日志与轨迹标准 (Log Standard)

## 1. 日志核心要素 (Audit Elements)
每一条日志条目必须包含以下“四元组”：
- **[时间戳]**：精确到秒 (YYYY-MM-DD HH:mm:ss)。
- **[操作人]**：姓名 + 角色 ID (例如：张三 [调度专员])。
- **[动作类型]**：如：创建、修改、审核、作废、手动同步。
- **[变更详情]**：记录修改了哪些字段（从 A 变为 B）。

## 2. 交互逻辑
- **展示顺序**：默认**逆序排列**（Time Descending），最新的动态位于最上方。
- **差异对比 (Diff)**：若修改字段较多，必须支持点击“查看详情”，以表格或 JSON Diff 形式展示变更。
- **自动采集**：核心业务动作（如修改金额、变更状态）必须由后端静默采集，严禁依赖前端手动触发日志。

## 3. 视觉表现
- **轨迹点状态**：最新一条轨迹点颜色设为 **Primary Blue**，历史轨迹点统一为 **Gray**。
- **多语言处理**：轨迹描述必须支持多语言映射，方便海外代理查看。
