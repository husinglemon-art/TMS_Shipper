# 06 日志与轨迹写作标准

## 1. Purpose

本规则用于帮助在 PRD 中把日志、轨迹和变更记录写清楚。

## 2. When To Use

适用于：

- 操作日志
- 审批轨迹
- 状态流转轨迹
- 关键动作留痕

## 3. Core Writing Points

- 写清楚每条日志至少包含什么信息
- 写清楚展示顺序
- 写清楚变更详情如何查看
- 写清楚哪些动作必须留痕
- 写清楚日志是否可被普通用户看到

## 4. Typical Veto

- 有关键动作但完全没有日志设计
- 无法追溯谁做了什么

## 5. Typical Guide

- 可补日志字段四元组
- 可补轨迹展示样式和权限规则
