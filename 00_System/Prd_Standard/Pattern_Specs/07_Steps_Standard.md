# 📶 Pattern Spec: 分步进度标准 (Steps Standard)

## 1. 进度状态定义
AI 必须明确每一步的四个状态表现：
- **Wait (待触发)**：置灰，仅显示步骤标题。
- **Process (进行中)**：当前停留步骤，高亮显示。
- **Finish (已完成)**：显示 ✅ 图标，允许点击回溯。
- **Error (异常阻断)**：显示 ❌ 图标，表示该步骤未通过校验或业务驳回。

## 2. 导航控制逻辑
- **线性约束**：默认不允许跳步。必须完成 Step N 的必填校验，方可解锁 Step N+1。
- **回溯逻辑**：若业务允许中途修改，点击“上一步”必须保留当前步骤已输入的数据（存入临时 State）。
- **状态同步**：进度条状态必须与后端业务状态机（Status Machine）强关联。

## 3. UI 红线
- **位置**：进度条必须固定在页面顶部或侧边栏，不随内容滚动而消失。
