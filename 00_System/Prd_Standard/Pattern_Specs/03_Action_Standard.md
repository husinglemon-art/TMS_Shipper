# 03 操作动作写作标准

## 1. Purpose

本规则用于帮助在 PRD 中把按钮、链接和批量操作写清楚。

## 2. When To Use

适用于：

- 列表页操作
- 详情页操作
- 表单提交
- 批量动作

## 3. Core Writing Points

- 写清楚动作名称
- 写清楚动作前置条件
- 写清楚执行后发生什么
- 写清楚危险动作是否需要二次确认
- 写清楚失败时反馈什么

## 4. Typical Veto

- 只写“点击执行”
- 不写前置条件和结果

## 5. Typical Guide

- 可补动作矩阵
- 可补禁用、隐藏、加载状态说明
