# 08 看板写作标准

## 1. Purpose

本规则用于帮助在 PRD 中把 dashboard 或指标看板写清楚。

## 2. When To Use

适用于：

- 首页看板
- 模块概览页
- KPI 或状态总览区

## 3. Core Writing Points

- 写清楚有哪些核心指标
- 写清楚指标单位和更新频率
- 写清楚空值或无数据如何处理
- 写清楚点击下钻逻辑
- 写清楚哪些指标最应该前置

## 4. Typical Veto

- 指标很多，但没有主次
- 指标卡片无法下钻或无法解释来源

## 5. Typical Guide

- 可补指标表
- 可补趋势说明和下钻路径
