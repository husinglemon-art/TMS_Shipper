# 🔍 Pattern Spec: 查询过滤区 (Filter Standard)

> **[引用准则]**：当页面包含搜索功能时，必须强制定义以下参数。

## 1. 字段定义矩阵
AI 必须为每个筛选项填充下表：
| 字段名称 | AntD 组件类型 | 校验逻辑 (Validation) | 默认值 | 占位/提示文案 |
| :--- | :--- | :--- | :--- | :--- |
| 示例：运单号 | `Input` | 长度限 20, 自动去空格 | 空 | "请输入完整运单号" |
| 示例：状态 | `Select` | 单选, 必选项 | "全部" | "请选择单据状态" |

## 2. 交互行为规范
- **触发机制**：明确是“输入即触发 (Debounce 500ms)”还是“点击【查询】按钮触发”。
- **联动逻辑**：若字段 A 的选择会影响字段 B 的选项（如：国家 -> 城市），必须明确定义。
- **重置逻辑**：点击“重置”后，所有字段回归默认值，并自动触发一次空条件查询。
