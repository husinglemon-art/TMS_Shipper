# PRD 检查拦截项模板

## 1. Purpose

本文件用于记录“必须拦截、必须补齐”的问题。

这些问题如果不修，通常不建议继续推进。

## 2. Typical Veto Cases

常见拦截项包括：

- 角色不清
- 主流程不闭环
- 异常处理完全缺失
- 版本边界不清
- demo 主线失焦
- 关键依赖未说明

## 3. Output Format

```markdown
# 拦截项

## 1. 文档信息
- 文档名称：
- 检查版本：
- 检查日期：

## 2. 拦截项清单
1. [问题内容]
   - 位置：
   - 影响：
   - 建议补法：

2. [问题内容]
   - 位置：
   - 影响：
   - 建议补法：

## 3. 继续推进建议
- 当前是否建议继续：
- 原因：
```

## 4. Writing Rule

- 只记录真正阻断推进的问题
- 每条必须说明影响
- 每条必须说明怎么补
