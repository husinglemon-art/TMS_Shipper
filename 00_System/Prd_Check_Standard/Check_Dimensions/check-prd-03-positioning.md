# 03 产品定位检查

## 1. Purpose

本维度用于检查 PRD 是否说清楚“为谁解决什么问题，提供什么价值”。

## 2. When To Use

优先用于：

- 新产品
- demo 价值表达
- 商业化产品或需要竞品对照的场景

## 3. Core Checkpoints

- 是否能一句话概括产品定位
- 是否明确目标用户或目标客户
- 是否明确核心价值主张
- 是否说明与竞品或替代方案的差异点
- 是否说明本次版本的定位边界

## 4. Typical Veto

- 无法一句话说清产品是什么
- 用户对象模糊
- 价值主张空泛，只有“大而全”表达

## 5. Typical Guide

- 可补充客户类型和典型场景
- 可补充差异化对照
- 可补充产品不做什么
