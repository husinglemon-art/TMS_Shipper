# 13 AI 功能检查

## 1. Purpose

本维度用于检查 PRD 中如果涉及 AI 功能，是否把价值、边界和风险说明清楚。

## 2. When To Use

仅在以下情况使用：

- 文档明确涉及 AI 功能
- 文档涉及智能推荐、自动生成、自动分析、对话式能力等

如果文档不涉及 AI，直接标记为“不适用”。

## 3. Core Checkpoints

- 是否说清楚 AI 功能要解决什么问题
- 是否说清楚用户为什么要用它
- 是否说明 AI 与人工的边界
- 是否说明错误输出或不可用时怎么办
- 是否说明数据隐私或敏感信息风险

## 4. Typical Veto

- 为了“加 AI”而加 AI
- AI 功能价值完全说不清
- 高风险动作完全交给 AI 且无人兜底

## 5. Typical Guide

- 可补人工确认机制
- 可补降级方案
- 可补效果验证指标
