# 10 商业与投入产出检查

## 1. Purpose

本维度用于检查 PRD 是否说明了商业价值或投入产出逻辑。

## 2. When To Use

优先用于：

- 商业化产品
- 需要做 ROI 说明的自研系统

## 3. Core Checkpoints

- 是否说明业务收益或价值目标
- 是否说明投入产出逻辑
- 商业化产品是否说明目标客户和收入逻辑
- 自研系统是否说明效率提升或风险降低价值
- 是否说明为什么优先做这件事

## 4. Typical Veto

- 价值完全说不清
- 商业化产品无任何商业逻辑
- 自研系统完全没有效率或收益预期

## 5. Typical Guide

- 可补 ROI 粗估
- 可补目标客户或业务影响描述
- 可补优先级依据
