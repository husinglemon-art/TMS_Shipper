# 04 场景与旅程检查

## 1. Purpose

本维度用于检查 PRD 是否把角色旅程、业务场景和流程触点说清楚。

## 2. When To Use

优先用于：

- `01_Question_Input.md`
- `03_PRD_Initial.md`
- demo 主线设计

## 3. Core Checkpoints

- 是否写出核心角色
- 是否写出场景的起点、终点和关键动作
- 是否说明场景发生在什么业务环节
- 是否覆盖关键摩擦点或卡点
- 是否能支撑旅程图或流程图

## 4. Typical Veto

- 没有场景，只有功能列表
- 角色与任务关系不清
- 流程起点和终点缺失

## 5. Typical Guide

- 可补充岗位旅程图
- 可补充线下与线上环节衔接
- 可补充多角色协同路径
