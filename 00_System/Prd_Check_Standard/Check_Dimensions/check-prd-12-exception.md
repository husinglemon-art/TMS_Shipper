# 12 异常与边界检查

## 1. Purpose

本维度用于检查 PRD 是否覆盖了关键异常、失败结果和边界条件。

## 2. When To Use

优先用于：

- `05_PRD_Final.md`
- 复杂流程
- 审批、状态流转、多人协同场景

## 3. Core Checkpoints

- 是否写出关键失败场景
- 是否写出灰态、不可执行场景
- 是否写出误操作或冲突处理
- 是否写出超时、撤回、驳回、退回等结果
- 是否写出边界条件和处理方式

## 4. Typical Veto

- 只有正常流，没有异常流
- 关键异常完全没写
- 流程一旦出错就没有后续处理办法

## 5. Typical Guide

- 可补错误提示文案
- 可补边界条件列表
- 可补异常状态图
