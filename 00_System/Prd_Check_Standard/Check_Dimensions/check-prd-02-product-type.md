# 02 产品类型适配检查

## 1. Purpose

本维度用于检查 PRD 的设计方式是否和产品类型匹配。

## 2. When To Use

优先用于：

- 新产品或新模块立项阶段
- 商业化产品与自研系统的差异判断

## 3. Core Checkpoints

- 是否明确这是自研系统还是商业化产品
- 是否明确这是业务型、工具型、交易型还是基础服务型产品
- 设计重点是否与产品类型匹配
- 如果是 SaaS，是否说明标准化与隔离要求
- 如果是自研系统，是否聚焦内部业务效率和流程支撑

## 4. Typical Veto

- 连产品类型都没有说明
- 设计方式与产品类型明显错位
- SaaS 产品完全没有隔离或标准化意识

## 5. Typical Guide

- 可补充产品类型的判断理由
- 可补充部署模式和适配边界
- 可补充自研/商业化带来的设计差异
