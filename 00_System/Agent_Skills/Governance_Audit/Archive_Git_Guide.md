# 🛠️ Skill: 版本归档与 Git 安全操作指引

## 1. 技能定位 (Definition)

本技能用于支持 PM 仓库中的版本归档、资产封存和 Git 安全同步。

说明：
本技能不强调生产发布，而强调文档资产与原型资产的可追溯性。

## 2. 核心原则 (Core Principles)

- 归档前先确认版本目录和目标路径
- 同步前先确认变更范围是否清晰
- 保持提交记录可读、可追溯、可回查
- 遇到冲突或不确定场景时优先熔断，不做冒险覆盖

## 3. 适用场景 (Use Cases)

- Phase 6: 原型资产归档
- Phase 9: Git 同步与版本封存
- 版本目录快照备份
- 主档更新后的留痕提交

## 4. 最低要求 (Minimum Requirements)

- 提交说明必须清晰表达版本号与变更范围
- 归档目录必须与版本号一一对应
- 不允许将无关测试文件或临时草稿混入正式提交
