# Research Analysis Skills

## Purpose

本组用于需求访谈、问题定义、用户任务分析、竞品研究和需求结构整理。

## Included Skills

- `Company_Research.md`
- `Problem_Statement.md`
- `Jobs_To_Be_Done.md`
- `User_Story_Enhanced.md`
- `User_Story_Mapping.md`
- `Artifact_Context_Intake.md`

## When To Use

- 做需求访谈
- 做竞品研究
- 定义问题边界
- 拆需求结构
- 阅读复杂原始材料

## Maintenance Rule

- 这是最适合按业务逐步替换的一组
- 后续新增 skill 时，优先从这一组开始补
