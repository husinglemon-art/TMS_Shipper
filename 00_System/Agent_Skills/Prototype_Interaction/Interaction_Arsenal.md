# 🧰 技能档案：[Skill_AntD] 企业级交互模式参考库

## 1. 技能定位 (Definition)
本技能是 [UE] 和 [Staff] 的核心约束。用于确保原型说明、页面结构和交互表达具备纯正的现代 SaaS 质感，彻底消灭“拼凑感”和“土味 UI”。

## 2. 组件映射绝对法则 (Component Mapping Laws)
在 Phase 2 规划与 Phase 3 原型表达时，遇到以下业务场景，**必须优先借鉴**对应的企业级交互模式：

- **【数据展示域】**
  - 多行数据：优先采用支持筛选、排序、批量查看的表格型结构，而不是简单平铺。
  - 核心指标看板：优先采用卡片化指标区，而不是杂乱文本堆砌。
- **【复杂表单域】**
  - 超过 5 个字段的表单：严禁一屏铺满。优先采用分步或分组表达。
  - 动态增减字段：必须明确增减逻辑、反馈方式和字段边界。
- **【阻断与反馈域】**
  - **危险动作 (删除/撤回)**：必须定义二次确认机制和危险提示样式。
  - **页面级空载**：必须提供明确的空状态文案和下一步引导。
  - **异步等待**：凡是涉及加载、切换或等待的区块，必须有可见的状态反馈。

## 3. 样式污染禁令 (Anti-Pollution)
- **严禁**在同一页面中混入大量不一致的表达方式。
- 间距、排版和分组必须保持统一，不得让评审者靠猜测理解层级关系。
