# 🧰 技能档案：[Skill_Mermaid] 业务可视化渲染引擎

## 1. 技能定位 (Definition)
本技能是 [PM] 和 [Architect] 的核心武器。用于消除自然语言的歧义，将隐性逻辑强制转化为物理可视化的拓扑图、时序图和状态机。

## 2. 强制调用场景 (Execution Triggers)
- **Phase 2 (页面流转)**：必须调用 `graph TD/LR` 渲染用户点击路径。
- **Phase 4 (状态封版)**：必须调用 `stateDiagram-v2` 渲染核心实体的生命周期。
- **Phase 7 (架构重绘)**：必须调用 `graph` 渲染系统微服务或目录拓扑。

## 3. 语法与渲染红线 (Syntax Red Lines)
- **绝对禁令**：严禁使用 ASCII 字符（如 `+---+` 或 `--->`）手搓假图表。必须且只能使用 ````mermaid ```` 代码块。
- **状态机规范 (State Machine)**：
  1. 必须包含明确的起点 `[*]` 和终点 `[*]`。
  2. 状态扭转的箭头上，必须标注触发该动作的**具体 API 或按钮名称**（例：`待调度 --> 运输中 : 点击[确认发车]`）。
  3. 必须包含至少一个【异常流转】分支（例：`运输中 --> 异常冻结 : 触发 SLA 告警`）。
- **时序图规范 (Sequence Diagram)**：
  1. 涉及前后端交互时，强制使用 `sequenceDiagram`。
  2. 必须包含 `alt` (条件分支) 或 `opt` (可选分支) 语法，来表现成功与失败的不同走向。
