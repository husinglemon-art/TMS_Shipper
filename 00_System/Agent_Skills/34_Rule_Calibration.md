# 🛠️ Skill: 规则自动进化与校准 (Self-Calibration)

> **[执行场景]**：当指挥官对 AI 生成的 PRD 执行了人工修改，并下达“校准规则”指令时触发。

## 📥 输入源 (The Diff)
1. **Source A**：AI 原始生成的 PRD (垃圾版/半成品)。
2. **Source B**：指挥官人工修改后的 PRD (理想版/硬核版)。

## ⚙️ 差分进化逻辑 (Evolution Logic)
AI 必须执行以下三个层级的对比分析：
1. **语言风格层**：分析指挥官删掉了哪些废话，替换成了哪些具体的动词。
   - *动作*：更新 `11_inspector.md` 的【禁止词黑名单】。
2. **逻辑颗粒度层**：分析指挥官增加了哪些异常校验、前置条件。
   - *动作*：更新 `Prd_Check_Standard/Check_Dimensions/` 中对应的维度文件（如 12-Exception）。
3. **视觉/排版层**：分析指挥官调整了哪些列表结构、加粗位置。
   - *动作*：更新 `10_UI_Aesthetic_Standard.md`。

## 📤 产出动作 (Outputs)
- **覆盖写入**：直接修改 `00_System/` 下的对应 `.md` 文件。
- **校准报告**：向指挥官汇报：“已识别 3 处风格偏好和 2 处逻辑漏洞，11 号检察员已完成进化。”
