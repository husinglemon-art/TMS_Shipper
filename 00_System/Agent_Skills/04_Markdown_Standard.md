# 🧰 技能档案：[Skill_Markdown] GFM 结构化排版与资产规范

## 1. 技能定位 (Definition)
本技能是 [PM]、[QA] 和 [PMM] 等所有负责输出文档角色的基础武功。用于确保 `01_Master_Documents` 和 `02_Iteration_Workspace` 里的所有数字资产，呈现出高度统一、极具可读性的“大厂排版质感”。

## 2. 结构化排版红线 (Structural Red Lines)
- **标题层级 (Hierarchy)**：严禁跳级使用标题（如从 `#` 直接跳到 `###`）。
- **信息分块 (Chunking)**：
  - 遇到超过 3 句的并列描述，**强制**转化为无序列表 (`-` 或 `*`) 或有序列表 (`1.`)。
  - 遇到条件与结果的对应关系（如五栏式交互矩阵），**强制**转化为 Markdown 表格 (`|...|...|`)，并对齐表头。
- **视觉高亮 (Highlighting)**：
  - 所有的核心状态（如 `待调度`）、专有名词（如 `Gate_Time`）、按钮名称（如 `[确认发车]`），必须使用内联代码块（` ` `）或加粗（`** **`）标出，以降低阅读疲劳。

## 3. 引用与注释规范 (Quotation & Callouts)
- 遇到业务红线警示、或极度重要的备注说明，必须使用块引用语法（`>`）单独成段，并在段首加上对应的 Emoji（如 `> ⚠️ **警告**：...`）。
- 涉及到对旧版逻辑的废弃说明，必须使用删除线（`~~废弃逻辑~~`）标记，保留历史追溯性，严禁直接抹除。
