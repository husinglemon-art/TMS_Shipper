# 🔍 Phase 1: 需求深度访谈记录 (Question Input)

## 0. 基本信息
- **项目名称**: 微信小程序登录注册模块
- **当前版本**: v1.0
- **时间戳**: 2026-04-01

## 1. 核心需求对齐 (Core Alignment)

### 1.1 登录方式
- **核心路径**: 微信一键授权 + 手机号验证码登录（支持切换）。
- **强制性**: 暂时不需要强制绑定手机号（即支持基础授权后访问，但在特定场景可能需要手机号）。
- **门禁策略**: 不支持游客模式。未登录用户强制停留在登录页。

### 1.2 高级安全
- **双因子认证 (2FA)**: 若触发安全策略，需支持 **人脸识别**。

### 1.3 身份逻辑 (Multi-Tenancy)
- **多重身份**: 登录成功后，需校验用户是否属于多个“货主”名下。
- **动态切换**: 若存在多个货主身份，需提供“切换身份”功能。

### 1.4 注册与溯源
- **邀请机制**: 支持链接邀请溯源。
- **自动关联**: 通过邀请链接注册的用户，自动归属于该货主并成为其名下“司机”。
- **拒绝处理**: 用户拒绝授权时，采用“软引导”降级方案而非暴力阻断。

## 2. 数据对齐要求
- **后端同步**: 所有用户信息需同步至后端，确保跨端一致性。
