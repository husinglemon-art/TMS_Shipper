# Stitch Assets

## Purpose

本目录用于存放面向 `Stitch` 的专用原型生成资料。

## Current Files

- `v1.0_Stitch_Prompts.md`：适合逐页生成的 Stitch 提示词

## Usage Suggestion

- 先使用 `Global Prompt`
- 再按页面顺序使用 `Screen 1` 到 `Screen 4`
- 若生成结果跑偏，可直接使用文档中的 `Recovery Prompts`
- 当前目录只存放 `Stitch` 相关资料，不混放其他工具内容
- 正式生成前，默认应先与用户确认是否本轮使用 `Stitch`
- 若主 prompt 为英文，为方便中文使用，应同步保留中文说明或中英文对照

## Related Files

- 上层目录中的 `v1.0_Page_Spec.md`
- 上层目录中的 `v1.0_Screen_Content.md`
- 上层目录中的 `v1.0_Wireframe_Notes.md`

## Language Rule

- 建议保留英文 prompt 以保证生成稳定性
- 同时保留中文用途说明、使用顺序说明和必要的中文对照，便于直接复用
- 推荐实际使用方式：英文 prompt 直接投喂工具，中文对照用于人工确认、复核和二次修改
