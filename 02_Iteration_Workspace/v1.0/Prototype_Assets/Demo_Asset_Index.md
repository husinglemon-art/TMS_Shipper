# Demo Asset Index

## Purpose

本文件用于管理 `v1.0` 演示相关的长期可复用原型资产。

## Current Demo Theme

- 主题：货主侧订单到承运商指派闭环
- 主场景：工厂到工厂内贸运输
- 支线说明：出海前程陆运
- 主角色：货主调度员

## Demo Boundary

- 主演示线：订单导入 -> 订单池 -> 运输规划 -> 承运商推荐 -> 确认指派 -> 任务生成结果
- FTL：主演示线
- LTL：同页对照区块
- 前程陆运：说明性支线，只通过标签和规则提示体现
- 不展开范围：司机执行、在途监控、签收回单、费率对账

## Tool Management Rule

- 默认推荐的原型生成工具为：`Stitch`、`Gemini_Canvas`
- 在实际生成任何工具 prompt 或原型前，应先确认当前使用哪一种工具
- 若用户补充其他工具，应在当前版本 `Prototype_Assets/` 下建立对应子目录集中管理
- 每种工具的资料不得与其他工具混放
- 若为保证效果使用英文 prompt，需同步保留中文说明或中英文对照
