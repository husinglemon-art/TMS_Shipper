# v1.0 Screen Content

## Purpose

本文件用于沉淀 `v1.0` demo 4 个主页面的示例展示内容，供后续线框图、高保真页面或原型工具直接引用。

使用原则：

- 内容以演示清晰为优先，不追求生产环境字段完备度
- 文案要服务“货主调度员决策闭环”
- 前程陆运只作说明性支线，不扩展为独立页面内容集合

## Global Labels

建议统一使用以下标签体系：

- 运输类型：`整车` `零担`
- 订单状态：`待规划` `规划中` `待确认指派` `已指派`
- 推荐标签：`系统推荐` `报价最低` `时效最优` `KPI 最优`
- 场景标签：`内贸工厂到工厂` `零担补位` `前程陆运说明`
- 运力状态：`可接单` `运力紧张` `暂不可用`
