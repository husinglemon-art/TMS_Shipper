## Step 1: First Round Input

### English

```text
Create a desktop prototype for a shipper-side transportation management control tower in China.

User:
- shipper dispatcher

- domestic factory-to-factory trucking

Workflow:
- order pool
- transportation planning
- carrier recommendation
- confirm assignment
- transport task result

Design direction:
- enterprise dashboard
- logistics control tower
- desktop-first
- high information density
- clean B2B interface
- clear hierarchy using tables, cards, tabs, tags, and action buttons

Now design screen 1: 订单池 / 待规划列表.

Screen goal:
- let users understand which orders are ready for planning

Layout:
- top navigation
- page title and subtitle
- source status hint below title
- one-row filter bar
- bulk action row
- wide table as the main content

Core modules:
- filter bar
- selected-count and action bar
- order table

Important fields:
- order number
- source
- pickup
- delivery
- weight and volume
- transport type
- required arrival time
- scenario tag
- current status

Visual emphasis:
- order status and transport type should stand out first
- main action button 进入规划 should be easy to find

Style:
- enterprise operations dashboard
- stable and data-first
```

## Step 4: Correction Prompts

### If it looks too consumer-facing

#### English

```text
Make the screen more like an enterprise operations dashboard and less like a consumer product. Increase information density, reduce decoration, and emphasize a clean filter bar and structured data table.
```

#### 中文对照

```text
请让页面更像企业运营后台，而不是消费端产品。提高信息密度，减少装饰性设计，重点强化清晰的筛选栏和结构化数据表格。
```

### If the table is too weak or too small

#### English

```text
Make the table the dominant element of the page. Increase the width and information density of the order table, and make the order status and transport type tags more prominent.
```

#### 中文对照

```text
请让表格成为页面主视觉。增加订单表格的宽度和信息密度，并让订单状态和运输类型标签更加突出。
```

### If the page loses the B2B tone

#### English

```text
Adjust the page to feel more like a logistics control tower for operations teams. Use cleaner spacing, less playful styling, and more structured enterprise UI patterns.
```

#### 中文对照

```text
请把页面调整得更像面向运营团队的物流控制塔。使用更克制的间距、更少的活泼样式，以及更结构化的企业级界面模式。
```
