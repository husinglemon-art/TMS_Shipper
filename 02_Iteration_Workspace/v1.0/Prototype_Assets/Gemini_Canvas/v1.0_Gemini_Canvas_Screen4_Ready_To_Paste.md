## Step 5: Correction Prompts

### If the result page feels too weak

#### English

```text
Make the success result panel more explicit and trustworthy. The user should clearly feel that the workflow is completed and the transport task has been created successfully.
```

#### 中文对照

```text
请让成功结果面板更明确、更可信。用户应能清楚感受到流程已经完成，并且运输任务已成功生成。
```

### If the page looks too celebratory

#### English

```text
Reduce celebratory visual language. Keep the page professional, operational, and stable, like a B2B logistics dashboard rather than a consumer success page.
```

#### 中文对照

```text
请减少庆祝式视觉语言。保持页面专业、运营型、稳定，更像 B2B 物流后台，而不是消费端成功页。
```

### If confirmation and result are not clearly separated

#### English

```text
Separate the confirmation stage and the result stage more clearly. The confirmation summary should feel like a final check, and the result panel should feel like an explicit completion state.
```

#### 中文对照

```text
请更清楚地区分确认阶段和结果阶段。确认摘要应像最终核对，结果面板应像明确的完成状态。
```
