# v1.0 Gemini Canvas Final Prompt Kit

## Purpose

本文件是 `v1.0` 面向 `Gemini Canvas` 的最终版 prompt 套件。

目标：

- 只保留当前最有效的生成方式
- 不再沿用此前分散、试错性质更强的旧资料作为主入口
- 统一为“生成前约束 -> 主线逐页生成 -> 小轮 review 修正 -> 停止条件”四段结构

## How To Use

1. 先确认 `Guardrails`
2. 再按页面 1 -> 2 -> 3 -> 4 顺序生成
3. 每轮 review 最多只修 2 个问题
4. 达到 `Stop Conditions` 后停止继续大改

## Part 1: Guardrails

### Main Storyline

- 主线：订单池 -> 运输规划 -> 承运商推荐 -> 确认指派 -> 任务结果
- 主场景：国内工厂到工厂内贸运输
- 核心页：承运商推荐页

### Side Branch Limit

- 支线：前程陆运说明
- 边界：只作为规则说明，不形成独立流程
- 页面 1、页面 2、页面 4 不让前程陆运成为主叙事主题
- 前程陆运优先停留在页面 3 的规则说明和候选降级逻辑中

### Non-Negotiable Display Rules

- 未通过截关/时效校验的候选不得与默认推荐候选平级展示
- 被降级候选可保留用于对比或审计，但只能做风险候选或次级候选
- 结果页优先突出任务生成成功和下一步入口，不扩展成执行联动主页面

### Tone And Language

- 页面语言应偏业务评审可理解的货主调度决策表达
- 避免：大平台、大中台、大优化系统、大执行指挥中心叙事
- 避免过多系统回写、技术编排、执行跟踪表达

### Stop Conditions

- 主场景不再跑偏
- 页面 3 推荐可信度成立
- 页面 4 结果页不再扩成执行系统页
- 剩余问题只属于轻量措辞或层级优化

## Part 3: Review Rules

### Review Discipline

- 每轮最多只修 2 个问题
- 优先修：主线偏移、数据不一致、推荐页可信度
- 不要把 5 到 8 个问题塞进同一轮修正里

### Stage 1 Fix Focus

- 修主线跑偏
- 修动态数据和选单一致性
- 修推荐页业务可信度

### Stage 2 Fix Focus

- 压支线戏份
- 压系统感、压技术联动叙事

### Stage 3 Fix Focus

- 只做最后轻修
- 如：进一步弱化规则卡标题、进一步降低系统联动存在感

## Part 4: Stop Conditions

- 主场景不再跑偏
- 页面 3 推荐可信度成立
- 页面 4 结果页不再扩成执行系统页
- 剩余问题只属于轻量措辞或层级优化

## Final Recommendation

- 当前 `v1.0` 使用 `Gemini Canvas` 时，优先以本文件为第一入口
- 只有在需要更细的单页控制时，再回看 `ScreenX_Ready_To_Paste` 文件
- 只有在已经拿到原型结果、并准备做定向修正时，再使用 `v1.0_Gemini_Canvas_Review_Fix_Prompts.md`
