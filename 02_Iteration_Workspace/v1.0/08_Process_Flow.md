# 08 流程图

## 1. 说明

本文件用于沉淀 `v1.0` 当前版本的主流程图、异常流程图和状态流图。

## 2. 主流程图

```mermaid
flowchart TD
    A[ERP/WMS 同步订单进入工作台] --> B[订单池 / 待规划列表]
    B --> C{是否勾选有效待规划订单}
    C -->|否| C1[停留在列表并提示先勾选订单]
    C -->|是| D[进入运输规划页]
    D --> E[识别订单摘要与关键约束]
    E --> F[给出 FTL 主线结论]
    F --> G[展示 LTL 对照说明]
    G --> H[进入承运商推荐页]
    H --> I[默认按综合评分排序展示候选]
    I --> J{是否存在前程陆运说明场景}
    J -->|否| K[直接比较候选并选择承运商]
    J -->|是| J1[先校验截关时间]
    J1 --> J2[将不满足截关要求的候选降级为风险 / 审计候选]
    J2 --> K
    K --> L[确认指派]
    L --> M[生成运输任务]
    M --> N[展示任务结果与后续入口]
```

## 3. 异常流程图

```mermaid
flowchart TD
    A[异常触发] --> B{异常类型}

    B -->|订单字段缺失| C[阻断进入有效规划结果]
    C --> C1[高亮缺失项并提示补齐]

    B -->|订单被锁定 / 规划中| D[阻断勾选或重复规划]
    D --> D1[提示由其他调度员处理中]

    B -->|无协议承运商| E[进入竞价 / 招标备选分支]
    E --> E1[提示人工介入或改走竞价]

    B -->|推荐结果过期| F[阻断确认指派]
    F --> F1[提示刷新结果后重试]

    B -->|任务生成失败| G[停留在结果反馈上下文]
    G --> G1[提示失败原因、重试或人工处理]

    B -->|批量部分成功| H[拆分成功与失败结果]
    H --> H1[展示失败摘要和后续处理建议]
```

## 4. 状态流图

```mermaid
stateDiagram-v2
    [*] --> 待规划
    待规划 --> 规划中 : 调度员进入规划页
    规划中 --> 待确认指派 : 已生成推荐结果或竞价结果
    待确认指派 --> 已指派 : 调度员确认承运商
    已指派 --> 任务已生成 : 系统生成运输任务
    规划中 --> 异常中断 : 关键信息缺失 / 无有效方案
    异常中断 --> 规划中 : 补齐数据后重新规划
    待确认指派 --> 规划中 : 返回调整方案
```

## 5. 流程边界说明

- 页面 1 重点是“哪些订单进入规划”，不是完整执行入口。
- 页面 2 重点是“为什么推荐整车”，不是复杂优化引擎展示。
- 页面 3 重点是“推荐依据透明”，不是全量竞价系统展示。
- 页面 4 重点是“闭环成立”，不是执行侧系统联动展示。
- 前程陆运只在页面 3 中以规则说明和候选降级逻辑出现，不作为独立主流程。
