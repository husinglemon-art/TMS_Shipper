# PRD 检查优化建议模板

## 1. Purpose

本文件用于记录 PRD 检查后的优化建议。

适用对象：

- `03_PRD_Initial.md`
- `04_Prototype_Notes.md`
- `05_PRD_Final.md`
- `PRD_Master.md`

## 2. How To Use

只记录“值得优化，但不阻断继续推进”的问题。

例如：

- 表达可以更清楚
- 页面层级可以更顺
- demo 节奏可以更聚焦
- 主档结构可以更完整

## 3. Output Format

```markdown
# 优化建议

## 1. 文档信息
- 文档名称：
- 检查版本：
- 检查日期：

## 2. 优化建议清单
1. [建议内容]
2. [建议内容]
3. [建议内容]

## 3. 优先改进方向
- 方向 1：
- 方向 2：

## 4. 说明
- 哪些建议适合当前版本立即修改
- 哪些建议可放入后续版本
```

## 4. Writing Rule

- 建议必须具体
- 建议必须能落到文档或原型说明中
- 不写空话，如“建议更好”“建议优化体验”
