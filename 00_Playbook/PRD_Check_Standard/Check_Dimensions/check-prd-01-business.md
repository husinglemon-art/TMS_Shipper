# 01 业务分析检查

## 1. Purpose

本维度用于检查 PRD 是否把业务背景、目标和问题说清楚。

## 2. When To Use

优先用于：

- `01_Question_Input.md`
- `03_PRD_Initial.md`
- 自研内部系统和业务型产品

## 3. Core Checkpoints

- 是否明确写出当前业务背景
- 是否明确写出核心痛点
- 是否说明问题带来的业务影响
- 是否说明目标是什么
- 是否说明信息来源来自访谈、数据或业务材料

## 4. Typical Veto

- 通篇看不出在解决什么业务问题
- 只有方案，没有当前现状
- 关键结论完全没有依据

## 5. Typical Guide

- 可补充更具体的数据支撑
- 可补充角色差异和不同诉求
- 可补充业务问题的优先级排序
