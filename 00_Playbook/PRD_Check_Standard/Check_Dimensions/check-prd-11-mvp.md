# 11 版本范围与演进检查

## 1. Purpose

本维度用于检查 PRD 是否把本次版本范围和后续演进关系切清楚。

## 2. When To Use

优先用于：

- demo 版本
- MVP 版本
- 分阶段交付版本

## 3. Core Checkpoints

- 是否明确本次必须进入的内容
- 是否明确本次不做的内容
- 是否保证本次范围能构成基本闭环
- 是否说明后续版本方向
- 是否避免“什么都想做”

## 4. Typical Veto

- 版本范围完全没有切边界
- MVP 不构成基本闭环
- demo 试图同时证明太多价值

## 5. Typical Guide

- 可补版本路线图
- 可补必须/建议/不进三级切分
- 可补后续版本演进备注
