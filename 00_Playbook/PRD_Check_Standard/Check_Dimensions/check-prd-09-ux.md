# 09 页面与交互检查

## 1. Purpose

本维度用于检查 PRD 是否把页面结构、用户动作和反馈方式写清楚。

## 2. When To Use

优先用于：

- `03_PRD_Initial.md`
- `04_Prototype_Notes.md`
- `05_PRD_Final.md`

## 3. Core Checkpoints

- 是否说明页面主任务
- 是否说明关键操作动作
- 是否说明反馈方式（成功、失败、加载、空状态）
- 是否说明危险动作的确认方式
- 是否说明页面层级和入口出口

## 4. Typical Veto

- 页面只有名字，没有动作
- 操作后没有反馈说明
- 关键异常提示完全缺失

## 5. Typical Guide

- 可补交互清单
- 可补空状态和灰态说明
- 可补关键页面的演示顺序
