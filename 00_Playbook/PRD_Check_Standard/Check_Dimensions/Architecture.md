# 06 架构与模块检查

## 1. Purpose

本维度用于检查 PRD 是否把模块关系、系统边界和结构分层说清楚。

## 2. When To Use

优先用于：

- 新系统设计
- 系统级规划
- `Product_Architecture.md` 回填前

## 3. Core Checkpoints

- 是否有模块关系图或架构图
- 是否说明主模块、上下游和支撑模块
- 是否说明系统边界和外部依赖
- 是否说明哪些能力是复用的，哪些是本系统负责的
- 如果只是模块级需求，是否避免过度展开企业架构

## 4. Typical Veto

- 系统级规划但完全无架构图
- 模块关系不清，边界模糊
- 主流程依赖外部系统却未说明

## 5. Typical Guide

- 可补主模块与支撑模块分层
- 可补外部依赖和责任归属
- 可补未来扩展方向
