# 07 数据与状态检查

## 1. Purpose

本维度用于检查 PRD 是否把核心数据对象、关键字段和状态变化说清楚。

## 2. When To Use

优先用于：

- 业务型系统
- 交易型平台
- 涉及复杂状态流的需求

## 3. Core Checkpoints

- 是否识别了核心数据对象
- 是否说明关键字段或关键数据项
- 是否有状态图或状态说明
- 是否说明主要数据之间的关系
- 是否说明数据归属或一致性风险

## 4. Typical Veto

- 核心对象都看不出来
- 有状态流却完全不写状态变化
- 数据关系与业务流程明显对不上

## 5. Typical Guide

- 可补关键字段表
- 可补状态机图
- 可补数据主源和同步说明
