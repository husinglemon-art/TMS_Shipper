# 08 流程与角色检查

## 1. Purpose

本维度用于检查 PRD 是否把流程责任、角色分工和协作路径写清楚。

## 2. When To Use

优先用于：

- 多角色协同流程
- 审批、流转、调度、协同类需求

## 3. Core Checkpoints

- 是否明确谁发起、谁处理、谁确认
- 是否明确角色间信息传递和任务流转
- 是否说明权限边界
- 是否说明关键节点的角色责任
- 是否说明流程中的等待、退回或升级情况

## 4. Typical Veto

- 角色很多，但分工完全不清
- 流程图不区分角色责任
- 涉及权限却完全没设计边界

## 5. Typical Guide

- 可补泳道图
- 可补角色权限矩阵
- 可补审批替代和升级机制
