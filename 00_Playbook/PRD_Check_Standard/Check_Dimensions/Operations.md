# 14 运营与上线跟踪检查

## 1. Purpose

本维度用于检查 PRD 是否考虑了上线后的培训、推广、跟踪和复盘。

## 2. When To Use

优先用于：

- 正式上线版本
- 需要做业务验收的版本
- 需要培训或推广的系统功能

## 3. Core Checkpoints

- 是否说明上线后谁负责跟踪
- 是否说明用户培训或使用引导
- 是否说明效果如何观察
- 是否说明需求反馈和问题收集入口
- 是否说明后续复盘机制

## 4. Typical Veto

- 版本要上线，但完全不考虑培训或跟踪
- demo 要转正式使用，却没有任何后续支持方案

## 5. Typical Guide

- 可补培训计划
- 可补上线后跟踪指标
- 可补用户反馈与复盘安排
