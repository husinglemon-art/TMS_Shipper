# 05 文档结构检查

## 1. Purpose

本维度用于检查 PRD 是否结构完整、层次清晰、可继续评审。

## 2. When To Use

优先用于：

- `03_PRD_Initial.md`
- `05_PRD_Final.md`
- `PRD_Master.md`

## 3. Core Checkpoints

- 是否包含背景、范围、流程、页面、异常、验收等核心部分
- 标题层级是否清晰
- 表格和列表是否用在该用的地方
- 是否有图而不是纯文字堆叠
- 是否有版本或修订信息

## 4. Typical Veto

- 结构混乱，看不出主次
- 缺少主流程、异常或范围边界等关键部分
- 只有大段自然语言，没有结构化表达

## 5. Typical Guide

- 可补版本记录
- 可补页面清单或模块清单
- 可补术语说明或引用来源
