# 10 视觉表达写作标准

## 1. Purpose

本规则用于帮助在 PRD 中把视觉表达要求写得清楚但不过度设计化。

## 2. When To Use

适用于：

- 原型说明
- 页面风格约束
- demo 视觉要求

## 3. Core Writing Points

- 写清楚整体信息层级
- 写清楚主色、辅助色和危险色的使用边界
- 写清楚留白和分区方式
- 写清楚是否强调轻量、简洁或高信息密度
- 写清楚什么风格禁止出现

## 4. Typical Veto

- 视觉要求完全缺失，导致页面风格失控
- 一页信息无主次，靠堆砌取胜

## 5. Typical Guide

- 可补页面层级说明
- 可补颜色和分区使用建议
