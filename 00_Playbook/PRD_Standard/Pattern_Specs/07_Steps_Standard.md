# 07 步骤流写作标准

## 1. Purpose

本规则用于帮助在 PRD 中把分步流程或步骤条写清楚。

## 2. When To Use

适用于：

- 分步表单
- 审批或执行流程
- onboarding 或 demo 主线

## 3. Core Writing Points

- 写清楚有哪些步骤
- 写清楚每步的状态
- 写清楚能否回退或跳步
- 写清楚步骤之间的数据保留逻辑
- 写清楚异常步骤怎么表现

## 4. Typical Veto

- 有步骤流但没有状态定义
- 步骤间切换条件不清

## 5. Typical Guide

- 可补步骤状态表
- 可补回退和异常规则
