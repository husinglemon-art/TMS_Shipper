# 05 详情区写作标准

## 1. Purpose

本规则用于帮助在 PRD 中把详情页写清楚。

## 2. When To Use

适用于：

- 详情页
- 详情抽屉
- 订单、运单、任务等对象详情

## 3. Core Writing Points

- 写清楚先展示什么信息
- 写清楚状态信息怎么呈现
- 写清楚空值和敏感信息怎么处理
- 写清楚哪些字段可交互
- 写清楚信息如何分组

## 4. Typical Veto

- 详情页只有字段堆叠，没有分组
- 状态信息不突出

## 5. Typical Guide

- 可补字段展示表
- 可补复制、脱敏、下钻等交互
