# 04 表单写作标准

## 1. Purpose

本规则用于帮助在 PRD 中把录入、编辑、提交类表单写清楚。

## 2. When To Use

适用于：

- 新增页
- 编辑页
- 弹窗表单
- 抽屉表单

## 3. Core Writing Points

- 写清楚字段名称和字段用途
- 写清楚默认值和是否可修改
- 写清楚必填、长度、格式等限制
- 写清楚提交时的校验逻辑
- 写清楚成功和失败反馈

## 4. Typical Veto

- 字段只列名字，不写规则
- 提交和校验逻辑完全缺失

## 5. Typical Guide

- 可补字段矩阵
- 可补表单分组和分步逻辑
