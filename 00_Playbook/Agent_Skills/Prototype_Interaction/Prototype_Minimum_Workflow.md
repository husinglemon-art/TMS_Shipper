# Prototype Minimum Workflow

## Purpose

本文件用于提供一页版的最小原型工作流，适合后续每个版本直接照着执行。

## Minimum Workflow

1. 先锁业务边界
2. 先写 `04_Prototype_Notes.md`
3. 先补 `Page Spec` / `Screen Content` / `Wireframe Notes`
4. 若使用 `Gemini_Canvas`，先写 `Generation Guardrails`
5. 先生成页面 1、2、3，再补页面 4
6. 每轮 review 最多只修 2 个问题
7. 达到“可评审”后停止继续大改
8. 回写原型结论到版本文档和资产索引

## Main Entrypoints

- 版本规则：`04_Prototype_Notes.md`
- 最终业务口径：`05_PRD_Final.md`
- 页面结构：`Page Spec`
- 当前原型工具主入口：最终版 `Prompt Kit`
- review 修正：`Review_Fix_Prompts`

## Stop Rule

- 不追求 AI 原型一步到位
- 只要已经达到“可评审”，就转入截图、讲解和评审材料阶段
