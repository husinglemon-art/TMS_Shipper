# Prototype Interaction Skills

## Purpose

本组用于把需求表达成可评审的页面结构、交互说明、展示资产和原型叙事。

## Included Skills

- `Evidence_Capture.md`
- `Journey_Map.md`
- `Interaction_Rules.md`
- `Demo_Storyline.md`

## When To Use

- 补原型说明
- 做页面流表达
- 准备截图或演示材料
- 输出交互逻辑和演示叙事

## Maintenance Rule

- 这一组可以根据你常用的原型工具逐步替换
- 替换时优先保证可评审性，不追求花哨命名
