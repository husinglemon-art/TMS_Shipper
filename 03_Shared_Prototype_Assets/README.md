# Prototype Assets README

## Purpose

本目录用于存放跨版本复用的原型展示资产，而不是某个单独版本的工作文件。

## Suitable Contents

- 通用截图命名规范
- 跨版本页面流模板
- 原型工具使用说明
- 通用演示素材模板
- 长期复用的展示资产

## Versioned Assets Rule

- 若资产强绑定某个版本，应优先放在 `02_Iteration_Workspace/v[版本号]/Prototype_Assets/`
- 若资产只服务单个版本归档，也可放在 `02_Iteration_Workspace/v[版本号]/Prototype_Archive/`
- 本目录不建议继续堆放 `v1.0`、`v1.1` 这类强版本绑定文件

## Naming Suggestion

- `template-screen-order-list.png`
- `template-flow-mainline.png`
- `prototype-tool-guide.md`

## Usage Rule

- 本目录更适合放长期可复用的展示材料
- 页面图尚未产出时，允许先用 Markdown 文档沉淀跨版本可复用的方法说明
- 具体版本的页面结构、内容文案、prompt 资料应回收到对应版本目录中管理
