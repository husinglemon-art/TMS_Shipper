# Master Documents README

## Purpose

本目录用于沉淀跨版本稳定结论，是 `TMS_Shipper` 的主档区域。

## Included Files

- `PRD_Master.md`: 稳定业务规则与模块定义
- `Product_Architecture.md`: 产品结构与流程拓扑
- `Module_Map.md`: 模块总览
- `Decision_Log.md`: 关键决策记录
- `Dashboard.md`: 当前状态与风险提示

## Usage Rule

- 日常需求先在 `02_Iteration_Workspace/` 中完成
- 只有稳定结论才合并到本目录
- 不在本目录中保存临时草稿或未定稿讨论

说明：
本目录当前只保留主档骨架模板，待真实版本启动后再逐步填充稳定内容。
